# Beispiel-Extension im Überblick

Was die Extension für deine Firma erledigt, für wen sie gedacht ist und was du als Administrator dafür wissen musst.

## Wofür die Extension da ist

Beschreibe hier in zwei, drei Sätzen das Problem, das die Extension löst.

## Erste Schritte

1. Extension installieren: `sudo aictl extension install example`
2. Unter `https://example.<deine-domain>` anmelden.
